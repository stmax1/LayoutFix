# LayoutFix

Переключатель раскладки RU/EN **только по запросу**, как Punto Switcher, но без автозамены.
Программа висит в трее и меняет текст, только когда ты нажимаешь горячую клавишу.

## Горячие клавиши (по умолчанию)

| Клавиша | Что делает |
|---|---|
| `Pause` | Исправляет последнее набранное слово (`ghbdtn` → `привет`). Повторное нажатие возвращает как было |
| `Shift+Pause` | Исправляет выделенный текст |
| `Scroll Lock` | Исправляет всю фразу, набранную после последнего Enter или клика мышью |

После исправления раскладка системы тоже переключается.

### Как поменять

Клик по значку в трее (или «Пуск» → «Настройки LayoutFix»), затем **Изменить** и нажать нужное сочетание.
Esc отменяет запись. Изменения применяются сразу, перезапуск не нужен.
- Сочетания, которые мешают набору текста (одиночные буквы, `Shift+буква`, пробел), не принимаются.
- Если сочетание уже занято другим действием, программа предложит его переназначить.
- Если на ноутбуке нет Pause, подойдут, например, `Ctrl+Alt+Space`, `F12` или `Ctrl+Shift+Z`.

Настройки хранятся в `%APPDATA%\LayoutFix\config.ini`.

## Установка

Запусти `LayoutFix-Setup-x.y.z.exe`. По умолчанию ставится без прав администратора.
Установщик предлагает автозапуск с Windows и ярлык на рабочем столе, а при обновлении сам закрывает старую версию.
Удаляется через «Параметры → Приложения».

## Сборка установщика

**Через GitHub (ничего не нужно ставить):** загрузи проект в репозиторий и создай тег:
```
git tag v1.0.0
git push --tags
```
GitHub Actions соберёт `LayoutFix-Setup-1.0.0.exe` и приложит его к релизу.
Ещё можно запустить вручную: вкладка Actions → Build installer → Run workflow.

**Локально на Windows:** нужны Python 3.10+ и Inno Setup 6 (`winget install JRSoftware.InnoSetup`), потом:
```
build.bat
```
Результат появится в `output\LayoutFix-Setup-1.0.0.exe`.

**Запуск без сборки:** `pip install -r requirements.txt`, затем `pythonw layoutfix.py`.

## Файлы

| Файл | Назначение |

| `layoutfix.py` | основная программа: трей, хуки клавиатуры, конвертация |
| `settings_ui.py` | окно настроек |
| `layout_map.py` | таблица клавиш QWERTY ↔ ЙЦУКЕН |

| `.github/workflows/build.yml` | автосборка установщика на GitHub |

## Ограничения

- В программах, запущенных от администратора, LayoutFix работает, только если его самого запустить от администратора.
- Буфер слова сбрасывается при Enter, Tab, стрелках, клике мышью, смене окна и сочетаниях с Ctrl/Alt/Win.
- Исправление выделенного текста временно использует буфер обмена, его текст потом восстанавливается.
